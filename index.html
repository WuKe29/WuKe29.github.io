AI Trading Agent — multi-agent LLM system

Python · LangGraph · LangChain · MCP · FastAPI · ~6,200 LOC · 2026
  • Multi-agent pipeline: deterministic code scans the universe, specialist agents each receive only their own read-only tool set, a supervisor decides — nothing in the pipeline can trade.
  • Unified trust model: agents propose, code executes — 22 write-operation tools denied at build time, single-use confirmation tokens with expiry and replay protection, position and stop-loss limits enforced in code.
